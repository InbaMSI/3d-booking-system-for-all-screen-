# Cinema booking frontend

This Next.js App Router application is the Phase 2 frontend. Run commands from
the workspace root; setup, routes, the mock/backend switch, and limitations are
documented in the root [README](../../README.md).

The local API adapter is the default. The auditorium is a labeled procedural
prototype, and no authorized trailer media is configured. Do not treat demo
holds or payment handoffs as confirmed bookings.
